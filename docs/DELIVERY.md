# VELORA v4.0 final project

27 active invitations: 6 curated Signature, 21 Editions. 63 repeated variants remain outside the gallery only for historical URL compatibility. All 90 current/historical invitation routes are exported.

Signature: Kandyan Garden, Celestial Vows, Royal Blue Seal, Pearl & Beeralu, Lotus Heirloom and Kandyan Vintage Ride. New dedicated couture lotus and lace pages replace their earlier generic variants.

Three bundled seven-second MP4 opening films use local artwork; no remote media dependency or live backend is needed. Native video playback advances on ended and includes Skip/Continue controls; reduced-motion visitors bypass the film. The optional asset-rendering script is included; FFmpeg/Pillow are not needed to run the website.

Preview bug fix: music controls no longer float and shrink the section beside them. Gallery and studio phone previews establish their own container dimensions. The royal first-screen portrait, names, date and venue use responsive spacing.

Reference study: Eventoura’s blue seal invitation; Invitation.lk Mandalaa Lotus and Pearl Lace. Original VELORA artwork, MP4 composition and native code adapt their visual directions and section structures. Exact third-party artwork/films were not copied.

Validation: TypeScript/production build/catalogue checks; six-item Signature gallery; royal video metadata and completed playback; pearl and lotus film/skip; preview section width equals phone screen width (328px in tested frame); pearl guest increment/local RSVP; lotus Sinhala switch; retained calendar, seating, wishes and gallery controls. No physical device testing or shared production RSVP service is included.
